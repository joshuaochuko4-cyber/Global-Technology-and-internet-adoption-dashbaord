# Global Technology & Internet Adoption Dashboard

## Project Overview

This project analyzes global technology adoption, internet accessibility, connectivity, and ICT development using the World Development Indicators (WDI) dataset.

The dashboard was developed in Microsoft Power BI to provide interactive insights across countries, regions, income groups, and years.

---

## Objectives

- Analyze global technology adoption trends (1960–2025)
- Compare countries using technology indicators
- Explore technology development by income group
- Build an interactive business intelligence dashboard

---

## Dataset

Source:
World Development Indicators (World Bank)

Indicators Used:
- Individuals using the Internet (% of population)
- Mobile cellular subscriptions
- Fixed broadband subscriptions
- Fixed telephone subscriptions
- ICT goods exports

---

## Tools

- Microsoft Power BI
- Power Query
- DAX

---

## Dashboard Features

- KPI Cards
- Interactive Slicers
- Line Chart
- Bar Chart
- Map
- Donut Chart
- Scatter Chart
- Detail Table

---

## Key Insights

- Global internet adoption has increased significantly since the early 2000s.
- High-income economies generally achieve stronger technology indicators.
- Technology adoption differs across regions and income groups.
- Interactive filters support detailed country and regional analysis.
